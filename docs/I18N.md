## 1. 구조

- **문장 원본은 `game/i18n/strings.csv` 한 장이다.** 열은 `keys,ko,en`. Godot 이 임포트해서
  `strings.ko.translation` / `strings.en.translation` 을 만든다(같이 커밋한다 - 새로 받은 저장소가 임포트 전에도 뜨게).
  CSV 를 고치면 `Godot --headless --path . --import` 를 한 번 돌린다(릴리스 빌드는 익스포트가 알아서 한다).
- **아이템 이름은 CSV 에 없다.** `items.json` 에 ko/en 이 같이 있고(그게 유일한 원본 - 스팀 아이템 정의도 거기서 나온다),
  `ShopCatalog` 이 처음 읽힐 때 `ITEM_<ID>` 키로 올린다(`Loc.AddMessages`).
- 기부 칭호(`DonationTable.Titles`)는 키를 들고 있다. 친구 칸에는 누적 기부량만 가고 칭호는 받는 쪽이 고르므로,
  서로 다른 언어여도 각자 자기 언어로 보인다.

## 2. 코드에서 쓰는 법 (`shared/Loc.cs`)

| 글자 | 쓰는 법 | 언어가 바뀌면 |
|---|---|---|
| 고정 글자 (버튼·제목·탭) | `Text = "MENU_SHOP"` - **키를 그대로** | Godot 컨트롤이 알아서 다시 그린다(auto translate) |
| 숫자·이름이 낀 글자 | `Text = Loc.F("BANANAS_N", n)` | 저절로 안 바뀐다 - `Loc.Changed` 를 듣거나 다음 갱신 때 다시 만든다 |
| 컨트롤이 아닌 곳 (트레이 메뉴, 글자 폭 계산) | `Loc.T("KEY")` | 직접 다시 쓴다 (`TrayIcon.RelabelMenu`) |

- 숫자 서식(`{0:N0}`)도 표 안에 쓴다 - 어순이 언어마다 달라서 조각을 이어 붙이지 않는다.
- 키는 대문자·밑줄(`BTN_OK` 처럼 접두어). **남의 글자(스팀 닉네임)를 그리는 라벨은 `AutoTranslateMode = Disabled`** -
  닉네임이 우연히 키와 같으면 번역돼 버린다(HUD 이름, 로비 랭킹·친구 목록 이름, 친구 칸 이름).
- 로그(`GD.Print`)·자체 검사 문구는 옮기지 않는다 - 화면에 안 나온다.

## 3. 언어 고르기

`Loc.Resolve(설정값, 스팀 언어)`:

1. 설정이 `ko`/`en` 이면 그것
2. 비어 있으면(자동) 스팀 클라이언트가 이 게임에 고른 언어(`SteamApps.GetCurrentGameLanguage`) - `koreana` 면 한국어, 나머지 전부 영어
3. 스팀이 없으면 Windows 언어

창을 만들기 전에 1·3 으로 한 번 고르고, 스팀이 붙은 뒤 2 로 다시 고른다(`OverlayShell.ApplyLanguage`). 스팀 언어 목록은
파트너 사이트 common 섹션 `languages { english, koreana }` (2026-10-21 도전과제 언어를 추가할 때 생겼다, A15 §2-1)라
라이브러리 > 속성 > 언어 에서 둘 중 하나를 고를 수 있다.

`--lang=en` / `--lang=ko` 는 설정·스팀을 무시하고 그 언어로 띄운다(세이브에 안 남는다) - 확인과 스크린샷용.

## 4. 영어 화면 확인 (2026-10-21)

`Godot --path . -- --store-shot=<폴더> --lang=en` 으로 전 장면을 찍어 봤다.

- 넘친 곳 두 군데를 고쳤다
  - 상점 탭 줄: "Decoration" 이 길어 [Collection] 탭이 화살표 뒤로 밀렸다 → 칸 이름 영어는 **Deco**
  - 친구 칸 둘째 줄: "1,853 punches · Banana D..." 로 잘렸다 → 칭호가 붙으면 영어는 단위를 뺀다 `1,853 · Banana Donor`
    (`REMOTE_STATS_TITLE`). 로비 랭킹에 punches 가 같이 보인다
- 설정 칸 라벨(150px)은 영어가 다 들어간다. "친구 커서 크기 (왼쪽 끝 숨김)" 의 괄호는 영어에서 뺐다 - 0 이면 오른쪽 값이 Off 로 보인다
- 용어는 스토어 영어 설명문(C1 §4-3)과 도전과제(A15)에 맞췄다: 타 = **punches**, 장식 = decoration, 로비 = lobby,
  칭호 영어 이름 = 같은 문턱의 도전과제 이름(Banana Donor · Jungle Donor · Jungle Benefactor)
- 목 친구·내 이름(디버그·스크린샷 전용)도 화면 언어를 따른다 - 영어 스크린샷에 한글 이름이 섞이지 않게

## 5. 스토어 스크린샷 (2026-10-21)

```
Godot.exe --path . -- --store-shot=<원판 폴더> --lang=en
python tools\make-store-screenshots.py <원판 폴더> --lang=en     # → assets/_store/screenshots/en/, description/en/
```

- 합성 스크립트가 `--lang=en` 이면 가짜 바탕화면의 시계·창 제목·문서 글자도 영어다. 목 친구·내 이름도 화면 언어를 따른다
- **스팀에는 영어가 본판, 한국어가 번역판이다.** 이전 스크린샷 5장(한글 화면)이 본판(English 칸)에 올라가 있어서 영어 사용자도
  한글 화면을 봤다 → 영어 5장을 새 본판으로 올리고, 장마다 한국어 그림을 번역판(Korean)으로 붙이고, 예전 5장을 지웠다.
  나머지 언어 사용자는 영어 그림을 본다
- 파트너 사이트 함정
  - 장마다 붙는 번역판 칸은 그 칸의 [Upload] 를 누르면 페이지가 다시 뜬다 - 한 장씩 올린다
  - 파일 이름 끝에 `_english` / `_koreana` 를 붙이면 언어가 자동으로 잡힌다
  - 스크린샷 줄의 (delete) 는 확인 없이 바로 지운다

### 5-1. 설명란 그림 (2026-10-26, 스토어 rev 8)

- 설명문은 그림을 **묶음 이름**으로 부른다(`[img]{STEAM_APP_IMAGE}/extras/section_punch[/img]`) - 그림을 바꿔도 BBCode 는 그대로다.
  묶음 안에서 스팀이 보는 사람 언어에 맞는 그림을 고른다
- 예전에는 묶음마다 한국어 그림이 **english** 칸에 들어가 있었다 → 영어 사용자도 한글 화면을 봤다
- 고친 방법: Description 탭 Upload Custom Images 에 `section_<이름>_english.<확장자>`(`description/en/`) 와
  `section_<이름>_koreana.<확장자>`(`description/`) 를 한꺼번에 놓고 [Upload] → Publish. 4묶음 × 2언어
  - 한국어 그림도 같이 올려야 한다 - 영어만 올리면 koreana 칸이 비어서 한국어 페이지도 영어 그림을 본다
  - 같은 파일을 다시 올리면 해시가 같아 diff 에 안 바뀐 것으로 나온다
  - 강화 그림은 두 언어 높이가 달라(252/267) "differing sizes" 경고가 뜨지만 그대로 올라간다
- 펀치 GIF 는 스팀이 영상(webm/mp4 + poster)으로 바꿔 `<video>` 로 넣는다 - 공개 페이지 HTML 에서 `<img>` 만 찾으면 안 보인다
- 한국어 커서·강화·친구 그림은 9/28 화면(탭 이름 "멀티", 기부 탭 없음)이다. 펀치 GIF 만 10/26 원판
