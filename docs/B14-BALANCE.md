## 2. 시뮬레이션 (`tools/balance-sim.py`)

가정: 켜 둔 동안 익는 대로 다 딴다(타건 충분 — 강화 끝이면 시간당 약 900타), 꺼 둔 동안은 슬롯이 한 번 차고 멈춘다.
시간당 수입은 강화 없음 22.5 → 강화 끝 162 (약 7배).

**장식 전부 모으는 날짜**

| 하루 켜 두는 시간 | 가격순으로 섞어 사기 (전 → 후) | 강화 먼저 (전 → 후) | 강화 안 함 (전 → 후) |
|---|---|---|---|
| 2시간 | 61 → 106일 | 50 → 88일 | 184 → 288일 |
| **4시간** | **32 → 55일** | **27 → 45일** | 95 → 149일 |
| 8시간 | 17 → 28일 | 14 → 24일 | 49 → 76일 |

- 첫 장식은 그대로 1일째(10바나나 ≈ 30분)
- 첫 강화 본전(플레이 시간): 가지 8 → 16시간, 빨리 익기 12 → 25시간, 황금 11 → 22시간. "강화 먼저" 를 고르면 첫 장식이 3주
  넘게 밀린다 — 이제 꾸미기와 효율 사이에 실제 고민이 있다
- 강화 먼저가 여전히 조금 빠르다(45 vs 55일) — 강화가 손해가 되면 안 되므로 이 정도 차이는 둔다

## 3. 남은 것

- **실사용 데이터로 다시 본다** — 시뮬레이션은 "켜 둔 동안 다 딴다" 가정이다. 실제 타건 수·켜 두는 시간을 스팀 통계
  (`STAT_KEYSTROKES`)와 서버 원장으로 보고 조정한다
- 하루 2시간 사용자는 3~4개월이다. 길다는 반응이 있으면 5티어만 낮춘다
- 장식이 업데이트로 늘면 완주 기간도 는다 — 새 장식은 같은 티어 표에 넣는다
- 마켓이 열리면 5티어(3,000)가 귀한 장식이 된다 — 그때 값을 다시 본다
