## 1. 한 줄 요약

```powershell
powershell -ExecutionPolicy Bypass -File tools\build-assets.ps1
```

**기본은 없는 것만 만든다.** 한 장만 다시 뽑으려면:

```powershell
tools\build-assets.ps1 -Id banana_01 -Force
```

시드가 매니페스트에 고정돼 있어서 **나머지 그림은 안 흔들린다.** 이게 매니페스트를
둔 이유다 — 프롬프트와 시드가 일회용 배치 스크립트에 박혀 있으면 한 장을 고치려고
전부 다시 뽑게 되고, 그러면 이미 마음에 든 그림까지 바뀐다.

## 2. 입력이 두 갈래다

에셋은 **성격에 따라 경로가 다르다.** 하나로 합치려다 실패한 기록이 §5에 있다.

### 2-1. 시트 슬라이스 — 엔티티 아트 (`slice.py`)

`assets/_source/` 에 받아 둔 스프라이트 시트를 자른다. 원숭이 펀치처럼 **같은
캐릭터가 여러 포즈로** 나와야 하는 것은 이쪽이다.

| 원본 | 종류 | 산출 |
|---|---|---|
| `Monkey.png` | 가로 8프레임 | `monkey_punch.png` (8칸 균등 그리드) + `.frames.json` |
| `Tree2.png` | 부품 아틀라스 3행 | 나무 2종 · 바나나 4종 · 잎 4종 낱장 |
| `Tree1.png` | 가로 8프레임 | `tree_growth.png` — 통짜 나무 성장용 **예비** (지금 씬은 슬롯을 따로 키운다) |

**프레임 위치를 숫자로 박지 않는다.** 알파 투영으로 찾으므로 시트를 새로 받아
여백이 달라져도 같은 명령이 그대로 돈다. 이미지는 언제든 갈아끼울 수 있어야 한다.

> **균등 그리드로 다시 조판하는 이유.** 받은 시트가 정확한 균등 그리드가 아니었다 —
> 프레임마다 팔이 칸 경계를 9px 쯤 넘었다. 그대로 `hframes` 를 걸면 **옆 프레임의
> 팔이 비쳐 들어온다.** 반대로 프레임마다 bbox 로 잘라 가운데를 맞추면 몸 위치가
> 프레임마다 달라져 **애니메이션이 덜덜 떤다.** 그래서 칸 기준 상대 위치를 보존한
> 채 칸 너비만 넓혀서 다시 깐다 — 상대 위치가 곧 그 프레임의 움직임이다.

### 2-2. 생성 — 커서 장식 (`gen.py` → `postprocess.py`)

낱장 정적 이미지는 로컬 ComfyUI 로 뽑는다. 장당 약 22초, API 요금 없음.

```
SDXL base + StickersRedmond LoRA (1024²·25스텝) → INSPYRENET 배경 제거 → _raw/*.png
  → 알파 임계 → 부스러기 제거 → bbox 크롭 → LANCZOS → 정사각 피벗 배치 → assets/
```

**출력 경로는 A5 가 이미 정해 뒀다.** `platform/CursorLayer.cs` 의 `ResolveTexture`
가 `res://assets/cursor/{slot}/{assetId}.png` 를 찾으므로, 파이프라인이 그 자리에
직접 떨구면 **A5 호출부는 한 글자도 안 바뀌고** 자리표시자에서 실물로 넘어간다.

전제: `C:\Tools\start_comfy.bat` 로 ComfyUI 가 127.0.0.1:8188 에 떠 있어야 한다.

## 3. 투명 오버레이라서 생기는 제약

일반 게임이면 배경에 묻혀 안 보였을 결함이 **바탕화면 위에서는 그대로 찍힌다.**

- **그림자·땅을 negative 프롬프트로 막는다.** `drop shadow`, `ground`, `grass`,
  `soil`, `pedestal`. 스프라이트 밑에 깔린 그림자가 알파로 살아남으면 벽지 위에
  회색 얼룩이 된다. (초기 `pixel` 스타일에 이게 빠져 있어서 실제로 나무·원숭이
  밑에 회색 타원이 남았다.)
- **부스러기를 지운다.** 배경 제거가 남긴 조각 하나가 벽지 위에 그대로 보인다.
  가장 큰 덩어리만 남기지 않고 **비율(2%)로** 자르는데, 꼬리나 반짝임처럼 본체와
  떨어져 있는 것이 정상인 부품이 있기 때문이다.
- **항목별 negative 가 따로 있다.** 스타일 공통에만 두면 안 된다 — 바나나에는
  `face, eyes` 를 막아야 하는데(안 막으면 눈·입이 달려서 나온다) 원숭이에 같은
  것을 막으면 얼굴 없는 원숭이가 나온다. 매니페스트의 `neg_extra` 가 그 자리다.

---

## 3-1. 프롬프트가 반복해서 실패하는 세 가지 (B9 1차 검수, 2026-09-21)

16장을 처음 뽑았을 때 **9장이 못 쓸 물건이었다.** 실패가 세 종류로 갈렸고, 셋 다
"negative 에 단어 하나 넣으면 되겠지" 가 안 통했다.

### ① 사물에 얼굴이 붙는다

바나나에 눈·입이 달려 나왔고(엔티티), `spark_02` 별에도 똑같이 달렸다. 스타일
LoRA 가 캐릭터 쪽으로 학습돼 있어서 **둥근 사물이면 의인화한다.**

→ 사물 항목에는 `face, eyes, mouth, smile, character, creature` 를 **항목별로**
넣는다. 스타일 공통에 넣으면 원숭이가 얼굴 없이 나온다.

### ② 낱개를 시켰는데 흩어진 세트가 나온다

`chunk_01`(바나나 조각), `leaf_02`(잎)가 한 장에 조각 여러 개가 흩어진 **스프라이트
시트처럼** 나왔다. `multiple` 하나로는 안 막힌다.

→ `multiple, several, many, group, collection, set, sprite sheet, scattered,
variations` 를 한 묶음으로 넣고, positive 에도 `exactly one ..., centered` 를 박는다.

### ③ 자세는 "무엇에" 를 빼야 나온다

hang 슬롯 6종 중 3종이 **매달리지 않고 그냥 서 있었다.** `hanging by one arm` 은
매달릴 대상이 없으면 무시되고, 대상(`branch`/`rope`)을 주면 **그 대상을 같이
그려 버린다** — 나머지 2종이 나뭇가지를 달고 나온 이유다. negative 에 `branch` 가
있는데도 그랬다.

→ **대상을 아예 언급하지 않고 자세만 묘사한다.** "both arms stretched straight up
overhead, legs hanging loose downward, dangling in mid air" 처럼 몸이 어떤
모양인지를 적고, negative 로 `standing, feet on ground, branch, rope, bar, vine`
을 막는다.

> **프롬프트를 고칠 때 시드도 같이 바꾼다.** 같은 시드를 두면 원래 구도에 끌려가서
> 프롬프트를 고쳐도 잘 안 벗어난다.

## 5. 밟은 것

**Godot 임포트가 소스 파일의 들여쓰기를 바꾼다.** `--headless --import` 는 에디터
레이아웃까지 불러오면서 스크립트 편집기에 열려 있던 `.cs` 를 제 설정(탭)으로 다시
저장한다. 2026-09-21 에 `game/GameRoot.cs` 306줄이 공백→탭으로 통째로 바뀌었다 —
**내용은 한 글자도 안 바뀌었는데 diff 는 전체 파일이 된다.** 조용히 넘어가면 그대로
커밋된다. `build-assets.ps1` §3 이 임포트 후에 이걸 검사해서 알려준다(자동으로
되돌리지는 않는다 — 진짜 공백만 고친 작업과 구분할 방법이 없다).

> **예방책은 저장소 루트 `.editorconfig` 에 이미 적혀 있었다** (2026-09-17, B3):
> Godot 에디터 설정 > Text Editor > Behavior > Indent > Type = **Spaces (Size 4)**.
> 각자 한 번 꺼 두면 끝난다. `.editorconfig` 자체는 Godot 이 안 읽는다 — 여기
> 검출은 그 설정을 안 해 둔 사람을 위한 그물이다.

**테마가 아직 임포트 안 된 폰트를 가리키면 Godot 이 죽는다.** `project.godot` 의
`gui/theme/custom` 을 켠 채로 폰트를 처음 임포트하면 세그폴트가 난다. 폰트를 먼저
임포트하고 테마를 켜면 된다.

**원본 시트는 `assets/_source/` 에 두고 `.gdignore` 를 깐다.** 안 그러면 원본
2.9MB 가 `.pck` 에 같이 실린다 — 게임은 잘라 놓은 것만 쓰는데도 그렇다.
