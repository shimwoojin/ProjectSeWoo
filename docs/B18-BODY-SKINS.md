관련: [B17 커서 장식](B17-CURSOR-REWORK.md) / [B13 강화](B13-UPGRADES.md) / [B14 밸런스](B14-BALANCE.md) /

## 0. 결정 (2026-09-28 갑)

나무와 본편 원숭이(나무를 치는 원숭이)에도 차이를 준다. 두 안을 검토했다.

| | 강화하면 겉모습이 바뀜 | 바나나로 사는 치장 아이템 |
|---|---|---|
| 좋은 점 | 강화의 약점("했을 때 눈에 보이는 변화가 없다", B13 §1)을 메운다. 친구가 내 진행도를 본다. 경제·스팀·마켓 무관 | 고르는 재미. 강화를 다 올린 뒤 바나나 쓸 곳. 마켓 대상 |
| 나쁜 점 | 고를 수 없다. 다 올리면 모두 같은 모습 | "원숭이" 분류가 커서·본편 둘이 된다. 완주 기간(B14 6~8주)이 는다. 세이브·전송·아이템 정의·서버·상점·C2 전부 손댄다 |

**섞는다.**

- **원숭이 → 치장.** 새 분류를 만들지 않고 **장착한 커서 원숭이 스킨을 본편 원숭이도 따른다.** 한 번 사면 두 곳이
  바뀌어 기존 6종의 값이 오르고, 경제·세이브·스팀 변경이 없다. 원숭이는 플레이어가 자기로 여기는 캐릭터라 강화에 따라
  억지로 바뀌면 오히려 아쉽다
- **나무 → 강화 단계.** 나무는 "바나나 만드는 기계" 라 진행도가 겉모습이 되는 것이 자연스럽다. 친구 칸에도 보인다

## 1. 원숭이

| | |
|---|---|
| 그림 | `assets/cursor/monkey/<id>/punch.png` — `monkey_punch.png` 와 같은 크기·같은 8칸. `monkey_01`(갈색)은 원판 그대로라 안 만든다 |
| 만드는 법 | `tools/make-body-skins.py` — 커서 스킨 표(`make-monkey-parts.py` 의 `SKINS`)와 **같은 털 마스크·같은 색 규칙**으로 원판 8칸의 털 색만 바꾼다. 프레임을 새로 생성하면 칸 사이 일관성이 깨진다(B17 §1-1) |
| 모자 (05) | 커서 머리에 그리는 모자를 칸마다 머리 자리(대기 칸 머리를 알파로 맞춘 위치)에 붙이고 `CAP_DROP` 14px 내린다 — 본편은 정수리 털이 위로 뻗어 그대로 붙이면 모자가 떴다 |
| 오랑우탄 (06) | 색만(주황). 커서 쪽도 장신구 없이 색만이라 같다 |
| 게임 | `Monkey.SetSkin(id)` — `GameRoot._Process` 가 매 프레임 장착 원숭이 id 로 부른다(바뀔 때만 일한다). 친구 칸은 받은 `EquippedMonkey` 를 카탈로그로 확인하고 부른다. 그림이 없으면 원판 |

## 2. 나무

| 단계 | 조건 (강화 레벨 합) | 그림 |
|---|---|---|
| 0 기본 | 0~2 | `tree_empty.png` (원판) |
| 1 무성한 나무 | 3~6 | `tree_stage_1.png` — 잎이 짙어지고 밑동 양옆에 덤불 |
| 2 꽃 핀 나무 | 7~10 | `tree_stage_2.png` — 1 + 왕관에 분홍 꽃 |
| 3 황금 나무 | 11 (전부 최대) | `tree_stage_3.png` — 잎이 금빛, 흰 꽃, 금빛 덤불, 반짝임. **완주 보상** |

- 합의 최대는 11 (가지 3 + 빨리 익기 4 + 황금 4). 표는 `UpgradeTable.TreeStageMinLevels` 한 곳 — 겉모습만이라 서버 사본은 없다
- **원판에 색·덧그림만 더한다.** 크기·줄기·왕관 자리가 그대로라야 `Tree.SlotAnchors`(텍스처 픽셀 좌표)가 모든 단계에 맞는다.
  꽃·반짝임은 송이 자리에서 38px 이상 떨어뜨린다(스크립트가 검사)
- 황금 잎은 색조를 한 값(40°)으로 통째로 바꾼다. 초록과 섞으면 올리브색으로 탁해졌고(첫 시안), 36°·밝기 그대로는 갈색 낙엽처럼 보였다(둘째).
  송이(노랑 약 50°)와 구분되게 살짝 붉은 쪽이다
- `Tree.SetStage` 는 단계가 바뀔 때 **모양을 다시 잰다** — 덤불·반짝임이 원판 알파 밖으로 나가고, 모양이 곧 그리기 영역(SetWindowRgn)이라 안 재면 잘린다

## 3. 전송 형식 v3

친구 칸에 친구의 나무 단계를 그리려고 `PlayerState.TreeStage`(1바이트, [13])를 더했다. **강화 레벨 자체는 안 보낸다.** v2 와는 서로 버린다.
C2 §2-5(한/영)와 `server/src/privacy.ts`, 기획서 §7-6 목록을 같이 고쳤다 — **공개 페이지는 서버를 다시 배포해야 바뀐다.**
